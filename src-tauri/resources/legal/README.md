# Packaged legal documents

These files are bundled with Ensō Time so the applicable terms and notices travel with
desktop distributions.

- `POLYFORM-NONCOMMERCIAL-1.0.0.txt`: canonical PolyForm Noncommercial 1.0.0
  terms and the Ensō Time Required Notice.
- `MPL-2.0.txt`: Mozilla Public License 2.0 for ActivityWatch code and local
  modifications.
- `THIRD_PARTY_NOTICES.md`: provenance, modifications, and third-party attribution.
- `COMMERCIAL.md`: commercial licensing policy and contact.
- `TRADEMARKS.md`: reserved names, isotype, icons, and logos.
- `PRIVACY.md`: beta privacy notice.
- `SECURITY.md`: security reporting and unsigned-installer information.

The repository license map defines the authoritative path boundaries. Third-party
materials always retain their original terms.
